## Attack surface and dependency cascade
- Tenant binding: browser hostname + Pages `SITE_ORGANIZATION_ID` -> middleware origin/fetch metadata -> bearer JWT or same-origin HttpOnly refresh cookie -> current D1 organization_memberships/role and branch_staff -> student row organization_id/branch_id -> R2 customMetadata studentId/organizationId/branchId and canonical stored key.
- R2 GET: browser <img> cannot set Authorization/X-Organization-ID, so verified same-origin HttpOnly cookie supports it; Native bearer GET must send organization header and bearer. An installed Native <Image> without headers is a compatibility blocker.
- R2 PUT/DELETE: reject foreign org/branch/student using DB predicate; verify custom R2 metadata before deletion. Legacy keys under avatars/ may have studentId but no org metadata; never bulk migrate/re-key existing records without explicit approval. For newly uploaded keys bind org/branch.
- Refresh: JWT token purpose and organization binding plus D1 session; refresh jti must be unique per rotation even in the same second. Atomic DELETE ... RETURNING prevents double use of one session under concurrency; still needs production D1 concurrency proof and recovery handling for failures after consumption.
- Native auth/login/register: X-Client-Platform and absent Fetch Metadata are spoofable. Cloudflare isolate-local rate limiting is not a durable abuse control. A trusted attestation/durable server-side rate limiter must be designed and verified without breaking deployed APKs; do not claim secure release until complete.
- Payments: tenant-specific callback origin allowlist, signed webhooks, matching organization_id + branch_id in metadata and D1, webhook idempotency under retries/concurrency. No live payments during source QA. Shared R2 and token/cookie rollout requires security coordination with existing live Hamarr Functions.
- Frontend/PWA: separate deterministic Hamarr and Manzur bundles, no Hamarr APK/download/logo leakage into Manzur, SW caches and return URLs pin tenant. Native clients may retain hamarr.cl /api; must not silently switch organization or branch.
